TARSUS FINDER — REVISI 4.8.0

Paket final untuk pengujian pengguna berdasarkan source code yang dikirim. Berisi penyempurnaan mobile-first, kartu tarif, navigasi, bantuan, tour, tentang aplikasi, serta perbaikan cache dan pemulihan pemuatan database.

PENTING: ini bukan autentikasi produksi. Login prototipe sisi browser tetap tidak aman untuk data atau kredensial sungguhan. Jangan menaruh secret di source code publik. Backend autentikasi diperlukan untuk pendaftaran akun sungguhan.

Pasang: unggah isi folder tarsus-backup-main ke repository GitHub Pages setelah membackup versi aktif. Setelah deploy, tutup dan buka ulang aplikasi atau lakukan hard refresh satu kali agar service worker versi baru terpasang. Periksa halaman Pusat Bantuan, Tentang aplikasi, pencarian tarif, Favorit, Riwayat, dan Pengaturan.

Daftar uji yang disarankan ada pada README-PASANG.txt. Bug yang masih ditemukan dapat dilaporkan bersama nama perangkat, browser, langkah reproduksi, dan tangkapan layar tanpa data sensitif.
