FOLDER ASSETS TARSUS FINDER

1. LOGO
   File yang dipakai: logo.svg
   Kamu boleh mengganti logo.svg dengan logo milikmu dalam format SVG.
   Jika logomu PNG/JPG, ubah src="assets/logo.svg" di index.html menjadi src="assets/logo.png" (sesuaikan nama file).

2. BACKGROUND FOTO
   Letakkan foto milikmu di folder ini dengan nama background.jpg.
   Foto dipakai pada latar aplikasi dan area hero. Efek blur, gelap, dan transparan diatur melalui style.css.
   Jika fotomu PNG/WebP, ubah dua referensi assets/background.jpg di style.css sesuai nama file.

PENTING: jangan mengubah app.js atau data.js untuk mengganti logo/background.
