TARSUS FINDER v1.2.0 — PAKET PEMBARUAN UI

ISI PAKET
- index.html
- style.css
- app.js
- data.js
- manifest.json
- sw.js

CARA MEMASANG
1. Ekstrak ZIP ini.
2. Unggah dan timpa enam file utama di root repository GitHub Pages tarsus-backup.
3. JANGAN hapus folder assets yang sudah ada. Pastikan file berikut tetap tersedia:
   - assets/logo.png
   - assets/background.jpg
4. Commit perubahan dan tunggu GitHub Pages selesai deploy.
5. Tutup aplikasi PWA sepenuhnya lalu buka kembali jika masih melihat tampilan lama.

PERUBAHAN UTAMA
- Menghapus hero besar dan elemen dekoratif yang berulang.
- Menghapus ilustrasi abstrak di area kosong hasil pencarian.
- Mengurangi pengulangan nama TARSUS Finder, badge, status workspace, dan label berbahasa Inggris yang tidak diperlukan.
- Menghapus monogram T dan nomor urut dekoratif dari kartu hasil.
- Menyederhanakan splash screen dan memperpendek durasinya.
- Menyempurnakan mode siang/malam dan kontras permukaan, teks, input, dropdown, dan kartu hasil.
- Saran stasiun tetap hanya menampilkan nama stasiun.
- Mesin pencarian dan data.js dipertahankan.

Catatan: file logo.png dan background.jpg tidak disertakan karena seharusnya sudah berada di folder assets pada repository milikmu.
