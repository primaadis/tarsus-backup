Tentang TARSUS Finder

Aplikasi pencarian tarif khusus kereta untuk membantu menemukan informasi tarif berdasarkan relasi stasiun.

Sistem Database

TARSUS Finder menggunakan tiga sumber data utama: MASTER_KA, MASTER_TARIF, dan MASTER_STASIUN.

Versi Aplikasi

Versi 1.0.0
Platform Android / Web
